# Anyaa Sachdev Portfolio

An interactive engineering and writing portfolio presented as a customized Mac desktop.

## Publish with GitHub Pages

1. Create a new public GitHub repository. A name such as `portfolio` works well.
2. Upload the root website files and the complete `assets` folder to the repository.
3. In the repository, open **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will provide a public address after the first deployment finishes.

The `.nojekyll` file keeps GitHub Pages from processing the site through Jekyll. All paths are relative, so the portfolio works from either a project address such as `username.github.io/portfolio/` or a custom domain.

## Local preview

Open `index.html` directly or serve this folder with any static web server.

## Updating the live site

Edit `index.html`, `styles.css`, `script.js`, or files inside `assets`, then push the changes to the selected GitHub Pages branch. GitHub Pages republishes the site automatically.

## Current interaction model

Dock icons open portfolio windows. Windows can be dragged, minimized, maximized, and closed. Search, menu-bar controls, project case studies, Messages prompts, résumé access, and external portfolio links all work without a framework or build step.
